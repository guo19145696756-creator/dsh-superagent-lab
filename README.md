## 怎么再跑一次

1. 在飞书找到 bot **「guoyong的飞书 CLI」**，私聊发一句请求
2. 约 1 分钟内，仓库里会出现一个新的 issue 和一个 `agent/` 前缀的分支
3. agent 会开 PR，**不会自动合并**（这是它自己的安全策略：人合并）

> ⚠️ **为什么不能从 GitHub 触发**：superagent 的 GitHub 触发要求「发起人 ≠ agent 账号」
> （`github-trigger.ts:63` 用 `sameName` 排除），而且 GitHub **不给 agent 自己发的 issue 发通知**。
> 飞书侧只看 `sender_type === 'user'`，所以私聊这条路才通。
